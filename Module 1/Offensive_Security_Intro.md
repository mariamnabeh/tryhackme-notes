
# Offensive vs. Defensive Security

## 1. Offensive Security

Simulates cyberattacks to identify and exploit vulnerabilities
before malicious hackers can find them.

**Main Goal:** Find security weaknesses.

**Common Roles:**
- Ethical Hacker
- Penetration Tester
- Red Team Operator

## 2. Defensive Security

Protects systems and networks by detecting, preventing,
and responding to cyber threats.

**Main Goal:** Protect systems and minimize security risks.

**Common Roles:**
- SOC Analyst
- Blue Team Operator
- Incident Responder

## 3. Key Differences

| Offensive Security | Defensive Security |
|---|---|
| Thinks like an attacker | Thinks like a defender |
| Finds vulnerabilities | Detects threats |
| Simulates attacks | Prevents and responds to attacks |
| Red Team | Blue Team |
