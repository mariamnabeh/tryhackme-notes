
# Module 2 — Defensive Security

## Notes
- Defensive Security focuses on protecting systems and detecting attacks.
- SOC (Security Operations Center): Monitors and responds to security threats.
- Brute Force: Repeated password attempts to gain unauthorized access.
- Threat Actor: The attacker responsible for an attack.
- Firewall: Blocks unwanted or suspicious network traffic.
- Account Lockout: Prevents further login attempts to a targeted account.
- Incident Response: Steps taken to handle a security incident.

## How to Write an Incident Report

1. Reference: Unique incident ID.
2. Report Date: Date of writing the report.
3. Time of Incident: When the attack happened.
4. Analysts: Team members handling the incident.
5. Classification: Severity (Low, Medium, High, Critical).
6. Status: Open or Closed.
7. Incident Narrative:
   - What happened?
   - Who was responsible?
   - What was the target?
   - What was the source IP?
   - What actions were taken?
8. Analyst Sign-off: Names and signatures.

## Example
A Brute Force attack targeted the /login page.
The attacker's IP was blocked, and the targeted account was locked.
