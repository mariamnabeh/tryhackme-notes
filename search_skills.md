
# Search Skills – TryHackMe

This room introduces useful cybersecurity research resources and how to use them to find and verify information.

### Topics Covered
- **Shodan:** Find exposed devices, open ports, and running services.
- **VirusTotal:** Analyze suspicious files, URLs, and domains.
- **CVE:** Identify known vulnerabilities.
- **CVSS:** Understand vulnerability severity scores.
- **Man Pages:** Find Linux command documentation and examples (e.g. `man nc`).
- **GitHub:** Explore repositories, README files, and security-related code and PoCs.

### Main Takeaway
- Use reliable sources to search for cybersecurity information.
- Know what information to look for.
- Always verify your findings.
